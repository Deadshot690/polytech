# Polymer Pulse Studio

<div align="center">

A modern industrial web platform showcasing **Kohinoor Polytech's** polymer manufacturing capabilities, sustainable production processes, products, and company information through a premium interactive user experience.

**Built with:** React • TypeScript • TanStack Start • Tailwind CSS • Three.js • Framer Motion

</div>

## Overview

Tanstack_Start_Ts is a modern full-stack ready web application developed to provide a premium digital presence for a polymer manufacturing company. The application focuses on presenting company information, products, manufacturing capabilities, sustainability initiatives, and business solutions through a responsive, visually engaging interface.

The project combines modern frontend technologies with interactive animations, 3D graphics, responsive layouts, and reusable UI components to deliver an enterprise-grade experience.

## Getting Started

### Prerequisites

- Node.js 18+
- npm or Bun
- Git

### Installation

```bash
git clone https://github.com/Deadshot690/polymer-pulse-studio.git
cd polymer-pulse-studio
npm install
```

or

```bash
bun install
```

### Run Development Server

```bash
npm run dev
```

or

```bash
bun run dev
```

Open:

```
http://localhost:3000
```

(or the URL shown in your terminal.)

---

## Build for Production

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
